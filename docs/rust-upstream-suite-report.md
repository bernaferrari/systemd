# Rust Upstream Focus Suite Report

This report is generated by:

```sh
./test/test-rust-upstream-focus-suite.sh
```

The script configures a Rust-enabled Meson build, runs the focus set:

- `test-unit-name`
- `test-unit-file`
- `test-calendarspec`
- `test-time-util`
- `test-parse-util`
- `test-id128`
- `test-socket-util`
- `test-transaction` (mapped to `test-engine` when no direct target exists)

and rewrites this file with pass/fail counts and pass-rate metrics.
